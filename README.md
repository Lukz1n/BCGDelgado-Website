## ✨ Sobre o Projeto

Este é o website institucional da **BCG DELGADO ELETRÔNICOS**, uma assistência técnica especializada em reparos de dispositivos móveis Android e iOS. O objetivo principal foi desenvolver uma plataforma online que refletisse a **experiência de mais de 10 anos** no mercado, a **qualidade dos serviços** e a **estética de um desenvolvedor sênior**, com um design moderno, elegante e repleto de animações, sem a aparência de um projeto genérico ou gerado por inteligência artificial.

O site oferece informações detalhadas sobre os serviços, a história da empresa e formas de contato, tudo isso em um ambiente visualmente atraente e funcional.

## 🎨 Design e Estética

O design foi uma prioridade, focado em criar uma experiência visual impactante:

*   **Paleta de Cores**: Predominância de **preto** (`#000000`) e **vermelho** (`#dc2626`), com tons de cinza para complementar. Essa combinação transmite sofisticação, energia e um toque tecnológico.
*   **Tipografia**: Seleção cuidadosa de fontes modernas e legíveis para garantir clareza e profissionalismo.
*   **Layout Responsivo**: Totalmente adaptável a qualquer tamanho de tela, proporcionando uma navegação impecável em desktops, tablets e smartphones.
*   **Animações e Microinterações**: Utilizando `Framer Motion`, foram implementadas diversas animações para um site dinâmico e interativo:
    *   **Entrada de Elementos**: Transições suaves e atrasos progressivos na Hero Section.
    *   **Efeitos de Hover**: Botões e cartões de serviço reagem com escala, sombra e brilho ao passar o mouse.
    *   **Fundos Animados**: A Hero Section possui um fundo com grade e gradientes pulsantes, criando uma atmosfera tecnológica.
    *   **Efeito de Digitação**: O título principal simula um efeito de digitação com cursor piscante, adicionando um toque moderno.
    *   **Efeito Glitch**: Títulos de seções com um sutil efeito *glitch* para uma estética "programador experiente".
    *   **Animações em Ícones**: Ícones de serviços com rotação e brilho na interação.

## 🛠️ Tecnologias Utilizadas

*   **[React](https://react.dev/ )**: Biblioteca JavaScript para a construção de interfaces de usuário reativas.
*   **[Vite](https://vitejs.dev/ )**: Ferramenta de build de frontend de próxima geração, oferecendo um ambiente de desenvolvimento rápido.
*   **[Tailwind CSS](https://tailwindcss.com/ )**: Framework CSS utilitário-first para estilização rápida e flexível.
*   **[Framer Motion](https://www.framer.com/motion/ )**: Biblioteca para animações de UI em React.
*   **[Lucide React](https://lucide.dev/ )**: Biblioteca de ícones de código aberto.

## ▶️ Como Executar Localmente

Para ter uma cópia local do projeto rodando, siga os passos abaixo:

1.  **Clone o repositório** (ou descompacte o ZIP que foi fornecido anteriormente):

    ```bash
    git clone https://github.com/Lukz1n/BCGDelgado-Website.git
    cd bcg-delgado-eletronicos
    ```

2.  **Instale as dependências** do projeto usando `pnpm`:

    ```bash
    pnpm install
    ```

    *Se você não tem `pnpm` instalado, pode instalá-lo globalmente com `npm install -g pnpm` e depois tentar novamente. Alternativamente, você pode usar `npm install` e `npm run dev`.*

3.  **Inicie o servidor de desenvolvimento**:

    ```bash
    pnpm run dev
    ```

    O site estará acessível em `http://localhost:5173` (ou outra porta disponível ) no seu navegador.
